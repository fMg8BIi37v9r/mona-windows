# Mona Universal Windows Runner

Sistem All-in-One: **Web Terminal (Tmux)** + **File Browser** + **Dual Cloudflare Tunnels** + **Notifikasi Telegram** di GitHub Actions Runner (`windows-latest`).

## Cara Menjalankan:
1. Buka tab **Actions** di repository ini.
2. Pilih workflow **Mona Universal Windows Runner** di panel kiri.
3. Klik **Run workflow**, pilih shell yang Anda inginkan (rekomendasi: **`powershell`**).
4. Klik tombol hijau **Run workflow**.
5. Link akses Web Terminal dan File Browser akan langsung dikirim ke Telegram Bot Anda!
